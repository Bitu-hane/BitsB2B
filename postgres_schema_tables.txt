
          BITSB2B MARKETPLACE - ENTERPRISE POSTGRESQL SCHEMAS

1. AUTHENTICATION & RBAC (ROLE-BASED ACCESS CONTROL) RATIONALE

  - Identity & Security Separation: Credentials and active sessions are decoupled
    from the core `users` identity table.
  - Multi-Role Support: Users can hold multiple roles simultaneously (e.g. `buyer`,
    `seller`, `importer`, `admin`) via the `user_roles` junction table.
  - Granular Permissions: Access rights are controlled via `permissions` mapped to
    `roles` in `role_permissions`.
  - Admin User Handling: An Admin is not a separate table, but a user record in `users`
    assigned the `ADMIN` system role in `user_roles` with root system permissions.


SECTION A: AUTHENTICATION, CREDENTIALS & RBAC TABLES



TABLE 1: users

Description: Primary user identity record (Buyers, Sellers, Dual Traders & Admins).

Attributes:
  - id                   : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - full_name            : VARCHAR(150)            NOT NULL
  - phone                : VARCHAR(30)             NOT NULL UNIQUE
  - email                : VARCHAR(150)            NULLABLE UNIQUE
  - avatar_url           : TEXT                    NULLABLE
  - is_active            : BOOLEAN                 DEFAULT TRUE
  - is_verified          : BOOLEAN                 DEFAULT FALSE
  - created_at           : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
  - updated_at           : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP


TABLE 2: credentials

Description: Stores passwords, hashes, and OTP secrets linked to a user.

Attributes:
  - id                   : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - user_id              : UUID                    NOT NULL REFERENCES users(id) ON DELETE CASCADE
  - password_hash        : VARCHAR(255)            NULLABLE -- Nullable for SMS OTP-only users
  - password_salt        : VARCHAR(255)            NULLABLE
  - otp_secret           : VARCHAR(100)            NULLABLE
  - failed_attempts      : INTEGER                 DEFAULT 0
  - locked_until         : TIMESTAMP WITH TIME ZONE NULLABLE
  - created_at           : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
  - updated_at           : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP


TABLE 3: authentications (or auth_sessions)

Description: Tracks active login sessions, JWT refresh tokens, and device metadata.

Attributes:
  - id                   : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - user_id              : UUID                    NOT NULL REFERENCES users(id) ON DELETE CASCADE
  - refresh_token_hash   : VARCHAR(255)            NOT NULL UNIQUE
  - device_info          : VARCHAR(255)            NULLABLE (e.g. 'Chrome 120 / macOS')
  - ip_address           : VARCHAR(45)             NULLABLE
  - expires_at           : TIMESTAMP WITH TIME ZONE NOT NULL
  - revoked_at           : TIMESTAMP WITH TIME ZONE NULLABLE
  - created_at           : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP


TABLE 4: roles

Description: Defines system and domain roles (`ADMIN`, `BUYER`, `SELLER`, `DUAL_TRADER`, etc.).

Attributes:
  - id                   : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - name                 : VARCHAR(50)             NOT NULL UNIQUE (e.g. 'Admin', 'Buyer', 'Seller', 'Dual Trader')
  - code                 : VARCHAR(50)             NOT NULL UNIQUE (e.g. 'ROLE_ADMIN', 'ROLE_BUYER', 'ROLE_SELLER')
  - description          : TEXT                    NULLABLE
  - is_system_role       : BOOLEAN                 DEFAULT FALSE
  - created_at           : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP


TABLE 5: permissions

Description: Granular system capabilities across catalog, orders, escrow & admin module.

Attributes:
  - id                   : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - name                 : VARCHAR(100)            NOT NULL UNIQUE (e.g. 'Create Product Listing')
  - code                 : VARCHAR(100)            NOT NULL UNIQUE (e.g. 'product:create', 'order:release_escrow', 'admin:manage_users')
  - module               : VARCHAR(50)             NOT NULL (e.g. 'catalog', 'orders', 'escrow', 'admin', 'inquiries')
  - description          : TEXT                    NULLABLE
  - created_at           : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP


TABLE 6: role_permissions (Junction Table)

Description: Maps granular permissions to roles (Many-to-Many).

Attributes:
  - role_id              : UUID                    NOT NULL REFERENCES roles(id) ON DELETE CASCADE
  - permission_id        : UUID                    NOT NULL REFERENCES permissions(id) ON DELETE CASCADE
  - granted_at           : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
  PRIMARY KEY (role_id, permission_id)


TABLE 7: user_roles (Junction Table)

Description: Maps roles to users (Many-to-Many, supports Admin assignment & Dual Trading).

Attributes:
  - user_id              : UUID                    NOT NULL REFERENCES users(id) ON DELETE CASCADE
  - role_id              : UUID                    NOT NULL REFERENCES roles(id) ON DELETE CASCADE
  - assigned_by          : UUID                    NULLABLE REFERENCES users(id)
  - assigned_at          : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
  PRIMARY KEY (user_id, role_id)



SECTION B: ENTERPRISE BUSINESS & MARKETPLACE CORE TABLES



TABLE 8: businesses

Description: Enterprise profile with dual-role capability flags & TIN verification.

Attributes:
  - id                     : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - user_id                : UUID                    NOT NULL REFERENCES users(id) ON DELETE CASCADE
  - name                   : VARCHAR(200)            NOT NULL
  - primary_role           : VARCHAR(50)             NOT NULL (e.g. 'importer', 'producer', 'wholesaler', 'reseller', 'institutional buyer')
  - capabilities           : TEXT[]                  DEFAULT ARRAY['can_buy', 'can_sell']
  - can_buy                : BOOLEAN                 DEFAULT TRUE
  - can_sell               : BOOLEAN                 DEFAULT TRUE
  - phone                  : VARCHAR(30)             NOT NULL
  - region                 : VARCHAR(100)            NOT NULL (e.g. 'Addis Ababa', 'Oromia', 'Hawassa')
  - city                   : VARCHAR(100)            NOT NULL
  - subcity                : VARCHAR(100)            NULLABLE
  - kebele                 : VARCHAR(50)             NULLABLE
  - landmark               : VARCHAR(200)            NULLABLE
  - tin_number             : VARCHAR(50)             NULLABLE
  - trade_license_number   : VARCHAR(100)            NULLABLE
  - is_verified            : BOOLEAN                 DEFAULT FALSE -- TRUE when TIN & Trade License verified
  - verification_status    : VARCHAR(30)             DEFAULT 'pending' -- ('verified', 'pending', 'unverified', 'rejected')
  - verified_at            : TIMESTAMP WITH TIME ZONE NULLABLE -- Admin approval timestamp
  - verified_by            : UUID                    NULLABLE REFERENCES users(id) -- Admin User ID who verified
  - established_year       : INTEGER                 NULLABLE
  - average_response_time  : VARCHAR(50)             DEFAULT '< 2 hours'
  - response_rate          : VARCHAR(20)             DEFAULT '100%'
  - rating                 : NUMERIC(3, 2)           DEFAULT 5.00
  - total_orders_completed : INTEGER                 DEFAULT 0
  - description            : TEXT                    NULLABLE
  - created_at             : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP


TABLE 9: categories

Description: Wholesale product categories.

Attributes:
  - id          : VARCHAR(50)             PRIMARY KEY
  - name        : VARCHAR(150)            NOT NULL
  - slug        : VARCHAR(150)            NOT NULL UNIQUE
  - description : TEXT                    NULLABLE
  - icon_name   : VARCHAR(50)             NULLABLE


TABLE 10: products

Description: B2B wholesale product listings published by enterprises with `can_sell = TRUE`.

Attributes:
  - id                    : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - seller_business_id    : UUID                    NOT NULL REFERENCES businesses(id) ON DELETE CASCADE
  - seller_user_id        : UUID                    NOT NULL REFERENCES users(id) ON DELETE CASCADE
  - category_id           : VARCHAR(50)             NOT NULL REFERENCES categories(id) ON DELETE RESTRICT
  - name                  : VARCHAR(255)            NOT NULL
  - description           : TEXT                    NOT NULL
  - price                 : NUMERIC(12, 2)          NOT NULL
  - currency              : VARCHAR(10)             DEFAULT 'ETB'
  - moq                   : INTEGER                 NOT NULL DEFAULT 1
  - unit                  : VARCHAR(50)             NOT NULL (e.g. 'pieces', 'sets', 'units', 'rolls')
  - stock_status          : VARCHAR(30)             DEFAULT 'in_stock'
  - stock_quantity        : INTEGER                 DEFAULT 0
  - stock_last_updated    : VARCHAR(50)             DEFAULT 'Just now'
  - lead_time             : VARCHAR(100)            DEFAULT '3-5 business days'
  - delivery_zones        : JSONB                   NOT NULL
  - images                : JSONB                   NOT NULL
  - specifications        : JSONB                   NOT NULL
  - created_at            : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP


TABLE 11: product_price_tiers

Description: Dynamic volume discount tier pricing per product.

Attributes:
  - id             : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - product_id     : UUID                    NOT NULL REFERENCES products(id) ON DELETE CASCADE
  - min_quantity   : INTEGER                 NOT NULL
  - price_per_unit : NUMERIC(12, 2)          NOT NULL


TABLE 12: orders

Description: Escrow-protected purchase orders.

CONSTRAINTS:
  - CHECK (buyer_business_id != seller_business_id)  -- Prevents self-dealing

Attributes:
  - id                      : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - order_number            : VARCHAR(50)             NOT NULL UNIQUE
  - buyer_user_id           : UUID                    NOT NULL REFERENCES users(id) ON DELETE RESTRICT
  - buyer_business_id       : UUID                    NOT NULL REFERENCES businesses(id) ON DELETE RESTRICT
  - buyer_business_name     : VARCHAR(200)            NOT NULL
  - buyer_name              : VARCHAR(150)            NOT NULL
  - buyer_phone             : VARCHAR(30)             NOT NULL
  - seller_user_id          : UUID                    NOT NULL REFERENCES users(id) ON DELETE RESTRICT
  - seller_business_id      : UUID                    NOT NULL REFERENCES businesses(id) ON DELETE RESTRICT
  - seller_business_name    : VARCHAR(200)            NOT NULL
  - status                  : VARCHAR(30)             DEFAULT 'placed'
  - escrow_status           : VARCHAR(30)             DEFAULT 'held_in_escrow'
  - escrow_provider         : VARCHAR(50)             DEFAULT 'telebirr'
  - payment_method          : VARCHAR(50)             DEFAULT 'telebirr'
  - payment_transaction_ref : VARCHAR(100)            NULLABLE
  - total_amount            : NUMERIC(14, 2)          NOT NULL
  - currency                : VARCHAR(10)             DEFAULT 'ETB'
  - delivery_address        : JSONB                   NOT NULL
  - tracking_number         : VARCHAR(100)            NULLABLE
  - freight_carrier         : VARCHAR(100)            NULLABLE
  - created_at              : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
  - confirmed_at            : TIMESTAMP WITH TIME ZONE NULLABLE
  - shipped_at              : TIMESTAMP WITH TIME ZONE NULLABLE
  - delivered_at            : TIMESTAMP WITH TIME ZONE NULLABLE
  - escrow_released_at      : TIMESTAMP WITH TIME ZONE NULLABLE


TABLE 13: order_items

Description: Individual line items inside a purchase order.

Attributes:
  - id            : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - order_id      : UUID                    NOT NULL REFERENCES orders(id) ON DELETE CASCADE
  - product_id    : UUID                    NOT NULL REFERENCES products(id) ON DELETE RESTRICT
  - product_name  : VARCHAR(255)            NOT NULL
  - product_image : TEXT                    NULLABLE
  - quantity      : INTEGER                 NOT NULL
  - unit          : VARCHAR(50)             NOT NULL
  - unit_price    : NUMERIC(12, 2)          NOT NULL
  - total_price   : NUMERIC(14, 2)          NOT NULL


TABLE 14: inquiries

Description: Product-anchored Request for Quotation (RFQ) inquiry threads.

CONSTRAINTS:
  - CHECK (buyer_business_id != seller_business_id)  -- Prevents self-messaging

Attributes:
  - id                   : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - product_id           : UUID                    NOT NULL REFERENCES products(id) ON DELETE CASCADE
  - product_name         : VARCHAR(255)            NOT NULL
  - buyer_user_id        : UUID                    NOT NULL REFERENCES users(id) ON DELETE CASCADE
  - buyer_business_id    : UUID                    NOT NULL REFERENCES businesses(id) ON DELETE CASCADE
  - buyer_business_name  : VARCHAR(200)            NOT NULL
  - seller_user_id       : UUID                    NOT NULL REFERENCES users(id) ON DELETE CASCADE
  - seller_business_id   : UUID                    NOT NULL REFERENCES businesses(id) ON DELETE CASCADE
  - seller_business_name : VARCHAR(200)            NOT NULL
  - topic                : VARCHAR(50)             NOT NULL
  - target_quantity      : INTEGER                 NULLABLE
  - target_price         : NUMERIC(12, 2)          NULLABLE
  - status               : VARCHAR(30)             DEFAULT 'pending_reply'
  - created_at           : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP


TABLE 15: inquiry_messages

Description: Messages exchanged within an RFQ inquiry thread.

Attributes:
  - id              : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - inquiry_id      : UUID                    NOT NULL REFERENCES inquiries(id) ON DELETE CASCADE
  - sender_user_id  : UUID                    NOT NULL REFERENCES users(id) ON DELETE CASCADE
  - sender_name     : VARCHAR(150)            NOT NULL
  - sender_business : VARCHAR(200)            NOT NULL
  - role_in_thread  : VARCHAR(20)             NOT NULL (e.g. 'buyer', 'seller')
  - text            : TEXT                    NOT NULL
  - created_at      : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP


TABLE 16: notifications

Description: User in-app notifications and system alerts.

Attributes:
  - id         : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - user_id    : UUID                    NOT NULL REFERENCES users(id) ON DELETE CASCADE
  - title      : VARCHAR(200)            NOT NULL
  - message    : TEXT                    NOT NULL
  - type       : VARCHAR(50)             NOT NULL
  - read       : BOOLEAN                 DEFAULT FALSE
  - created_at : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP


TABLE 17: sms_logs

Description: Audit log of outbound SMS OTP & milestone alerts.

Attributes:
  - id       : UUID                    PRIMARY KEY DEFAULT gen_random_uuid()
  - phone    : VARCHAR(30)             NOT NULL
  - message  : TEXT                    NOT NULL
  - sent_at  : TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
